## Implemented behavior

### Searchable native choices

`ui/menu.rs` adds native text search to multi-choice model/agent/config menus.
All query words match case-insensitively across the label and description.
Filtering preserves original controller indices, selected state and active choice
identity. The list remains virtualized, including a tested 10,000-entry catalog.

Empty results cannot activate an action. Escape clears a nonempty search before
dismissing. Spaces remain editable input. Enter acts once on a matching release;
held keys, query changes, focus loss and modified key combinations cannot commit
a stale choice. Native preedit is left to the existing text-entry handler rather
than used as menu confirmation. A real operating-system IME composition journey
is still required in the platform acceptance matrix.

The menu retains the original 150 ms opacity/scale entrance and reduced-motion
preference. Filtering does not recreate the entity or restart its entrance.
The compact composer Add menu intentionally retains its existing non-search
layout. Saved UI font preferences now apply to menu chrome. Search/check/provider
marks use the existing bundled Synara assets, not substitute icon artwork.

The controller still validates task/agent/session/generation identity and owns
configuration acknowledgement. Search does not connect an agent, submit a prompt,
change approval policy or fabricate unavailable model capabilities.

### Rich native transcript

`ui/markdown.rs` renders GFM tables with header/body borders, inline styles, empty
cells, left/center/right alignment and a horizontally scrollable native viewport.
Task-list state is read-only, with original check glyphs. It does not expose a
fake editable checklist backed only by local rendering state.

Fenced code has a language label and a native Copy action using Synara's existing
Copy icon. Clipboard contents preserve Unicode, whitespace and the final newline.
An empty fenced block no longer leaks code presentation to the following text.
HTML remains inert text. Links retain the existing web-URL validation. Rendering
and copying neither execute code nor rewrite the stored transcript.

No production backend, ACP schema, database schema, dependencies or original asset
files were changed. Chat creation/reuse, Project/Chat/Studio scopes, the original
mark/icon pack, work summaries and basic settings already existed at the starting
checkpoint and are not counted as new work here.

filenames and validated commit IDs. Only a closed list of picker/Markdown/test
paths uses the focused presentation workflow. Unknown paths, backend/dependency
