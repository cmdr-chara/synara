# Synara

A native coding-agent workspace written in Rust, with a GPUI desktop interface.

Coding agents connect through a shared ACP adapter. The application owns its workspace, task, thread and conversation models independently of the wire protocol.

Local and SSH execution share a process-host boundary. External agent runtimes are separate processes, not application dependencies.

Development is in progress. Build and platform verification must be completed before this branch is used with valuable workspaces.
